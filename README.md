# 🌳 Árvore das Profissões

Este repositório apresenta uma **árvore genealógica das profissões**, um projeto desenvolvido para mapear e visualizar as origens, ramificações e conexões entre diferentes carreiras e áreas de atuação ao longo do tempo.

## 📂 Estrutura do Repositório

* 🖼️ **[imagem-arvore-das-profissoes](./imagem-arvore-das-profissoes)**: Representação visual completa da árvore genealógica das carreiras.
* 📝 **[pesquisa.md](./pesquisa.md)**: Levantamento teórico, referências e anotações utilizadas na construção do projeto.

## 🎯 Objetivo
Facilitar a compreensão de como diferentes profissões evoluíram, se transformaram ou deram origem a novas especialidades no mercado de trabalho.
